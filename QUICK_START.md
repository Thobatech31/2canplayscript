# Quick Start Guide

Get the 2CanPlay AI Assistant up and running in 5 minutes!

## 1️⃣ Get an OpenAI API Key

1. Visit [OpenAI Platform](https://platform.openai.com/api-keys)
2. Sign up or log in
3. Click "Create new secret key"
4. Copy the key (starts with `sk-`)
5. Add credits to your account at [Billing](https://platform.openai.com/account/billing)

**Cost**: ~$0.00015 per question with GPT-4o-mini (very cheap!)

## 2️⃣ Install the Extension

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (toggle top-right)
3. Click **Load unpacked**
4. Select the `2canplayscript` folder
5. Done! Extension is now installed

## 3️⃣ Configure

1. Click the extension icon in Chrome toolbar
2. Paste your OpenAI API key
3. Select **GPT-4o Mini** (recommended)
4. Click **Save Settings**
5. Ensure toggle is **ON**

## 4️⃣ Start Playing

1. Visit [2canplay.ng](https://2canplay.ng)
2. Log in and start a trivia game
3. Watch for the floating AI panel when questions appear
4. Use AI suggestions to answer questions

## That's It! 🎉

The assistant now works automatically.

### Tips for Best Results

✅ **Good internet connection** - Faster AI responses  
✅ **Use GPT-4o Mini** - Fast enough for 12-second window  
✅ **Check confidence levels** - Trust high confidence answers  
✅ **Read explanations** - Verify AI reasoning  
✅ **Use your judgment** - AI is not 100% accurate  

### Common Issues

| Problem | Solution |
|---------|----------|
| Panel not showing | Refresh the page |
| "API key not configured" | Check popup settings |
| Slow responses | Check internet, use GPT-4o Mini |
| Wrong answers | Check confidence, use judgment |
