ImageMagick is not installed. Please create icons manually.

Quick method:
1. Visit https://favicon.io/favicon-generator/
2. Create icons with:
   - Text: "2C" or "🤖"
   - Background: #667eea
   - Font: Any readable font
3. Download and extract
4. Rename to:
   - icon16.png (16x16)
   - icon48.png (48x48)
   - icon128.png (128x128)
5. Place in the icons/ folder

Alternative: Use any image editor to create simple squares
- Size: 16x16, 48x48, 128x128 pixels
- Color: Purple gradient or solid #667eea
- Save as PNG with transparent background
