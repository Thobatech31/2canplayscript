## 🚀 Quick Setup (2 minutes)

### Step 1: Get FREE Gemini API Key

1. **Visit Google AI Studio**:
   - Go to https://aistudio.google.com/app/apikey
   
2. **Sign in with Google Account**:
   - Use any Google account (Gmail, etc.)
   - No payment method required!
   
3. **Create API Key**:
   - Click **"Create API Key"**
   - Select **"Create API key in new project"** (or use existing project)
   - Click **"Create"**
   
4. **Copy Your Key**:
   - Your key starts with `AIza...`
   - Click **"Copy"** button
   - Save it somewhere safe

✅ **Done!** You now have a FREE API key.

---

### Step 2: Configure Extension

1. **Open Extension**:
   - Click extension icon in Chrome toolbar
   - Find "2CanPlay AI Assistant"
   
2. **Enter Settings**:
   - **AI Provider**: Select **"Google Gemini (FREE)"**
   - **API Key**: Paste your `AIza...` key
   - **AI Model**: Select **"Gemini Pro"** (default, recommended)
   - **Verification Mode**: Select **"Strict"** (highest accuracy)
   - Check ✅ **"Enable multi-stage verification"**
   
3. **Save**:
   - Click **"Save Settings"**
   - Status should show **"Active"** with green dot

---

### Step 3: Test It!

1. Visit https://2canplay.ng
2. Start a trivia game
3. Wait for question to appear
4. AI panel appears in 4-6 seconds
5. See verified answers with confidence levels!

## 📊 Gemini Free Tier Limits

### What You Get FREE

- **60 requests per minute** (RPM)
- **1,500 requests per day** (RPD)
- **1 million tokens per day**

### What This Means

**In Strict Mode** (2-3 API calls per question):
- Can process **20-30 questions per minute**
- **500+ questions per day**

**In Balanced Mode** (2 API calls per question):
- Can process **30 questions per minute**
- **750+ questions per day**

**In Fast Mode** (1 API call per question):
- Can process **60 questions per minute**
- **1,500 questions per day**

**Bottom line**: FREE tier is MORE than enough for regular use! 🎉

## 🔧 Troubleshooting Gemini

### "API key not valid"

**Solutions**:
1. Check key starts with `AIza`
2. Copy the entire key (no spaces)
3. Generate a new key if needed
4. Ensure API is enabled in Google Cloud Console

### "Quota exceeded"

**Solutions**:
1. You hit the free tier limit (rare)
2. Wait 1 minute (RPM limit) or 24 hours (daily limit)
3. Enable billing in Google Cloud Console
4. Switch to Balanced or Fast mode (uses fewer API calls)

### "JSON parsing error"

**Solution**:
- Gemini sometimes returns markdown-wrapped JSON
- Extension automatically extracts JSON
- If persists, try different model (Flash or 1.5 Pro)

### Responses are slow

**Solutions**:
1. Switch to **Gemini 1.5 Flash** (faster)
2. Use **Balanced mode** instead of Strict
3. Check your internet connection
4. Check Google AI status
