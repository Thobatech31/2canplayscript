## 🎯 Installation Steps (Summary for Friends)

### 1. Download Extension
- Go to https://github.com/Thobatech31/2canplayscript
- Click green "Code" button → "Download ZIP"
- Extract ZIP file

### 2. Install on Chrome
- Open `chrome://extensions/`
- Enable "Developer mode"
- Click "Load unpacked"
- Select extracted folder

### 3. Get API Key
- Visit https://platform.openai.com/api-keys
- Create account → Create API key
- Add $5-10 credits to account

### 4. Configure
- Click extension icon in Chrome
- Enter API key
- Select GPT-4o + Strict mode
- Save

### 5. Play!
- Visit 2canplay.ng
- Start trivia game
- AI panel appears automatically
